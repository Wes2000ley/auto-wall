# Auto-Wall Live

Enable this Foundry 14 module in **Manage Modules**, then open
**Wall Controls → Auto-Wall Live**. A newly copied module may require a Foundry
restart before it appears in the module list.

**1** wall, **2** door, **3** invisible wall, **4** window, **5** light.
**B** toggles brush/rectangle walls. Right drag pans, middle drag erases a
rectangle, wheel changes brush size, Ctrl+wheel zooms, Ctrl+Z undoes a complete
edit. Pause editing to interact normally with the game.

Completed gestures save directly to native scene documents. There is no export
step or ML setup. Automatic detection uses the selected palette in a local worker.
Review it on your artwork; shared scenery colors can still cause false positives.

See the [full controls, installation, conflict behavior and validation guide](https://github.com/Wes2000ley/auto-wall/blob/main/foundry/README.md).
